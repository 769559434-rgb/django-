📌 CSS 引入方式详解

外部样式表 · 内部样式表 · 行内样式 —— 三种方式实战对比

方式 ①

🔗 外部样式表

使用 <link rel="stylesheet" href="style.css"> 引入独立的 .css 文件。
优点：可复用、便于维护、分离结构与表现。
👇 下方区域样式由外部样式表控制：

📦 外部样式区块

我的背景、边框、字体等属性都是由外部CSS文件定义的。实际项目中将样式写在单独 .css 文件中再 link 引入。

✅ 背景色浅蓝，圆角边框，文字深灰色 —— 外部样式生效。

方式 ②

📄 内部样式表

使用 <style> 标签在 HTML 文档的 <head> 中定义样式。
适用单页面独特样式，当前页面大部分样式（卡片、背景、按钮）都来自内部样式表。

💡 这个卡片背景、整体布局、圆角阴影等都是由内部样式表定义的。
方式 ③

✍️ 行内样式

直接在元素的 style 属性中编写CSS，优先级最高（通常用于临时调试或单独微调）。

🎨 这个区域的样式完全由行内样式控制！
背景粉色、边框玫红、圆角阴影等均写在 style 属性中。
⚡ 优先级提醒：行内样式 > 内部样式表 > 外部样式表 (同权重下后面的覆盖前面的)。日常开发推荐使用外部样式表。
📖 练习总结： 你现在已经见证了CSS三种引入方式。尝试修改外部样式模拟内容或内部样式，观察页面变化，加深理解。
